# war3_battle — 魔兽争霸3互联网联机工具

让分处各地的朋友像在局域网一样联机打魔兽争霸3。三人各自在家运行客户端，魔兽的"局域网游戏"列表里会直接出现彼此开的房间，点加入即可对战。

## 工作原理

魔兽争霸3 的局域网模式分两个阶段：

1. **发现阶段**（UDP 6112）：进入局域网界面时广播 `0x2F W3GS_SEARCHGAME` 查询包，开图方回复 `0x30 W3GS_GAMEINFO` 游戏信息包；
2. **加入阶段**（TCP）：`0x30` 包尾携带主机接受连接的 TCP 端口，加入方连接该端口后发送 `0x1E W3GS_REQJOIN`，此后聊天、传图、加载、100ms 操作帧等全部游戏数据都走这条 TCP 长连接。

本工具在两阶段上做透明代理：

| 角色 | 行为 |
|---|---|
| 主机侧客户端 | 周期广播 `0x2F` 发现本机开的魔兽游戏，把原始 `0x30` 包登记到服务端房间 |
| 加入侧客户端 | 把房间里的 `0x30` 包**改写包尾端口**为本地代理端口后广播到本机网络，魔兽局域网列表直接显示该游戏 |
| 加入对战 | 魔兽 TCP 连接本地代理端口 → 服务端中继 → 主机侧客户端连 `127.0.0.1:游戏端口`，双向透传 |
| 玩家互连 | 魔兽协议原生支持"玩家间直连不通时经主机中转"，全员走中继无兼容问题 |

所有客户端主动连出到服务端，不需要家庭路由器做任何端口转发。

## 系统要求

- Windows 10 / 11（客户端），服务端任意平台（提供 Linux 与 Windows 版本）
- 魔兽争霸3（推荐 1.21 - 1.29 经典版，冰封王座或混乱之治）
- 一台有公网 IP 的服务器（VPS）做中继，开放一个 TCP 端口

## 获取与构建

直接使用仓库 `dist/` 目录下的预编译产物：

- `w3bridge-gui.exe` — Windows 图形界面客户端（推荐，双击即用）
- `w3bridge.exe` — Windows 命令行客户端
- `w3bridge.ps1` — PowerShell 版客户端（单文件脚本，兼容系统自带 PowerShell 5.1）
- `w3bridge.cmd` — 双击启动器（配合 w3bridge.ps1 使用）
- `w3bridge-linux-amd64` / `w3bridge-linux-arm64` / `w3bridge-linux-armv7` — Linux 客户端（网关模式用，见下文）
- `w3bridge-server.exe` — Windows 服务端
- `w3bridge-server-linux-amd64` — Linux 服务端（VPS 用这个）

需要自行编译时安装 Go 1.27+，在项目根目录执行：

```powershell
powershell -File build.ps1
```

## 部署

### 1. 服务端（VPS）

推荐用 `deploy/` 下的脚本安装为 systemd 服务（开机自启、崩溃自动重启）。把服务端二进制和 `install.sh` 传到服务器同一目录：

```bash
chmod +x install.sh
sudo ./install.sh
```

不带参数时会自动查找脚本同目录或上级 `dist/` 目录下的 `w3bridge-server-linux-amd64`，也可以显式指定：`sudo ./install.sh /path/to/w3bridge-server-linux-amd64`。

安装后常用命令：

```bash
systemctl status w3bridge        # 查看状态
journalctl -u w3bridge -f        # 查看日志
sudo ./uninstall.sh              # 卸载服务
```

默认监听 51234，改端口编辑 `/etc/default/w3bridge` 里的 `LISTEN` 后 `sudo systemctl restart w3bridge`。记得放行防火墙的对应 TCP 端口。

不用脚本也可以直接前台运行：`./w3bridge-server-linux-amd64 -listen :51234`。

### 2. 客户端（每人一台电脑）

**图形界面版（推荐）**：双击 `w3bridge-gui.exe`，界面里已按默认参数填好：

- 服务端地址：`war3.aiunit.com:51234`
- 房间名：`666`
- 玩家名：自动填入当前 Windows 用户名

确认后点"启动"即可，日志实时显示在窗口下方。游戏类型与版本都会自动识别。

**命令行版**：

```powershell
.\w3bridge.exe -server VPS的IP:51234 -room 666 -name 老崔
```

**PowerShell 版**（功能与 exe 版一致，共用同一服务端）：

双击 `w3bridge.cmd` 即可启动（Windows 对 `.ps1` 默认是"编辑"而非"运行"，启动器解决双击运行问题，退出后保留窗口方便看日志）。也可以右键 `w3bridge.ps1` →"使用 PowerShell 运行"，或在命令行执行：

```powershell
powershell -File w3bridge.ps1
```

所有参数默认与图形界面版相同：服务端 `war3.aiunit.com:51234`、房间 `666`、玩家名自动取当前 Windows 用户名。需要修改时手动指定（参数名与 exe 版含义相同）：

```powershell
powershell -File w3bridge.ps1 -Server 1.2.3.4:51234 -Room 666 -Name 老崔 -Pass abc
```

单文件脚本，无需编译环境，源码可直接查看修改。

三人约好相同的 `-room`（房间名），`-name` 随意。可选 `-pass` 设置房间密码。

### 网关模式（游戏机零安装）

客户端不需要装在游戏机上，只需要和游戏机**在同一个局域网**。把客户端跑在同网段的任意设备上（树莓派、NAS、软路由、旧电脑都行，用 `dist` 里的 `w3bridge-linux-*` 版本），游戏机什么都不用装：

- 开图的游戏机：照常在魔兽里建局域网游戏，网关自动发现并发布到房间；
- 加入的游戏机：照常在魔兽局域网列表里看到房间游戏，点击加入；
- 网关负责全部发现、公告与流量转发，日志也在网关上看。

启动命令与普通客户端完全相同，无任何额外参数。同一局域网里的多台游戏机可以由一台网关统一服务。

### 3. 开打

1. 开图的人照常在魔兽里创建局域网游戏，客户端日志出现"发现本机游戏并发布"即登记成功；
2. 其他人打开魔兽的"局域网"游戏列表，几秒内会出现该游戏（显示原地图名和房主名）；
3. 点击加入即可，缺图的玩家游戏会自动从其他玩家传图（建议提前放好相同地图更稳妥）。

注意：魔兽选项里"局域网 TCP/IP 游戏"的端口需与客户端 `-game-port` 一致（默认 6112）。

## 命令行版参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `-server` | 必填 | 服务端地址，例如 `1.2.3.4:51234` |
| `-name` | 必填 | 玩家名（显示在房间里） |
| `-room` | `666` | 房间名，三人约好一致即可 |
| `-pass` | 空 | 房间密码，可留空 |
| `-game-port` | `6112` | 魔兽局域网端口（游戏选项里的端口） |
| `-proxy-base` | `26112` | 本地代理端口起始值，每个远程游戏占一个端口 |

服务端参数只有一个 `-listen`（默认 `:51234`）。

## 常见问题

**魔兽局域网列表刷不出房间游戏**
- 确认开图方客户端日志有"发现本机游戏并发布"；
- 工具会自动识别游戏类型（冰封王座/混乱之治）与版本（覆盖 1.05 - 1.50，无需手动填写）；但三人魔兽本体必须是同一个版本（版本不一致游戏会互相忽略）；
- Windows 防火墙弹窗需给 `w3bridge.exe` 放行（专用和公用网络都勾上）。

**点加入没反应或加入失败**
- 看加入方客户端日志有无"已连上远程游戏"，失败会有具体错误；
- 确认 `-game-port` 与魔兽设置里的端口一致。

**能看到房间但进去后卡住**
- 多半是缺地图导致传图失败，建议三人提前放好相同地图。

## 目录结构

```
cmd/w3bridge/          命令行客户端入口
cmd/w3bridge-gui/      图形界面客户端入口
cmd/w3bridge-server/   服务端入口
internal/w3gs/         W3GS 协议包构造与解析（含 GBK 转码）
internal/protocol/     客户端与服务端的帧协议
internal/server/       房间管理与 TCP 流中继
internal/client/       局域网发现、游戏公告、TCP 代理
deploy/                服务端 systemd 安装与卸载脚本
dist/                  预编译产物
```
